PostFlowX easy setup for non-technical users

If Resolve Engine says Start failed, Helper setup needed, or Unknown action:

1. Double-click Install_PostFlowX_Helper.command in this folder.
2. Wait until the window says Installation complete.
3. Chrome will open chrome://extensions. Click Reload on PostFlowX.
4. Open PostFlowX > Settings > Resolve Engine.
5. Click Run Easy Check.

Resolve Engine is optional. IMF Validation still works without Resolve; Resolve only adds extra decode/conform confidence checks.
