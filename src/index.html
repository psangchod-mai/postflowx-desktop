Pulls Prep 2.0 — How to Use
1
Import your timeline

Drag any timeline file onto the left event panel or the NLE timeline canvas, or click Import ▼ in the panel header. Pulls Prep 2.0 accepts:

.edlCMX 3600 EDL — the universal interchange format from any NLE or DI system. .fcpxmlFCP X XML — from Final Cut Pro X, DaVinci Resolve 19+, or Premiere via export. .fcpxmldFCP X Package folder — drop the entire folder; PostFlowX reads the internal XML automatically. .xmlFCP 7 / xmeml — from Premiere Pro, older Resolve, or FCP 7. .otio / .otiozOpenTimelineIO — open interchange format for pipeline integration. .aleAvid Log Exchange — Avid bin export; imports clip metadata and reel names. .aafAdvanced Authoring Format — Avid Media Composer sequences.
For .fcpxmld packages, drop the whole folder — not the XML file inside it. PostFlowX finds the correct XML within the package structure automatically.
2
Load a proxy video

Drop a flattened sequence proxy onto the video player area (right panel), or click the Video button in the player hint. The proxy should cover the full sequence in record TC — one continuous file. Supported formats: .mov, .mp4, .mxf, .avi, .r3d, .mts.

Auto start TC: PostFlowX reads the TC from the filename automatically. A file named DLS_101_01_00_00_00.mov sets Start TC to 01:00:00:00. Override manually in the Start TC input at the top of the player if needed.

Next session, a ↺ Reload button appears automatically — click it to re-link the same file without browsing again.
3
Sync video to timeline

Click any event row in the list — the video seeks to that clip's record in-point. Verify the frame matches the cut. If it is off, scrub manually with ← / → until aligned, then adjust the Start TC field to lock the offset. All subsequent seeks will then be frame-accurate.

CONFORM mode auto-arms sync and sorts by record TC for the fastest alignment workflow.
4
Mode: ALL OFF — explore the raw timeline

Clicking ALL OFF resets every Quick Setting and shows the complete imported timeline with no filtering, sorting, or processing. Use this as a starting point to verify clip count, check reel names, inspect raw source TCs, or explore an unfamiliar EDL before committing to a mode.

The NLE timeline canvas below the event list shows all clips on their original tracks in record-TC order. You can scrub, zoom, and navigate freely in this view regardless of mode.

5
Mode: CONFORM — build a conform / DI pull EDL

CONFORM sorts by record TC and applies Merge + Flatten to remove duplicate handles. It auto-arms video sync so the proxy snaps to the timeline. Use this for turnovers destined for DaVinci Resolve color, Baselight, or any DI system that needs clean reel names and source TC ranges.

How to export:

Pull EDLCMX 3600 EDL with all conform clips, handles, and reel names — drop directly into Resolve or Baselight for a media pull. VFX Breakdown CSVSpreadsheet with reel, clip, source TC, record TC, duration, handles — for production tracking. Package (ZIP)Everything bundled: EDL + CSV + FCPXML + XML in one archive.
Use Handles field to add head/tail frames. Per-row overrides in the HDL column let you set a different handle for any individual clip.
6
Mode: VFX RENAME — pull from renamed DaVinci Resolve clips

Use this when editorial has already renamed clips in DaVinci Resolve (or another NLE) to the approved VFX shot naming convention. Pulls Prep reads the clip name from the timeline as the VFX shot name — no marker placement required.

Workflow:

  1. In DaVinci Resolve Edit page, rename clips to your VFX shot names (e.g. LMP_101_060)
  2. Export timeline as EDL or FCPXML from Resolve
  3. Import that timeline into Pulls Prep 2.0
  4. Switch to VFX RENAME — the SHOTS column auto-populates from clip names
  5. Review and export
Pull EDLEDL with shot names embedded as clip comments — import into any NLE for VFX pull conform. Markers XML (All NLEs)Downloads FCPXML (Resolve / FCP X) + FCP 7 XML (Premiere) simultaneously. VFX Breakdown CSVFull spreadsheet: reel, clip, shot name, TC, duration, flags, notes.

CUT DiFF — How to Use
1
Load OLD and NEW timelines

Drop an OLD (previous cut) and NEW (current cut) timeline into the two source zones at the top. Always load the earlier version as OLD and the later version as NEW — the direction determines which way EXTENDED and TRIMMED are reported.

Accepted formats: .fcpxml · .edl · .xml · .otio · .ale · .aaf

Optionally drop your OLD and NEW video files onto the upper / lower half of the timeline canvas to unlock filmstrip thumbnails, video compare, and the pixel-level content diff graph.
2
Analyze — understand the diff types

Click Analyze. Every clip in the NEW cut is matched to the best OLD clip by clip name + reel. The result is one of five classifications:

NEW Clip exists only in the NEW cut. Never seen by VFX, audio, or music — always HIGH RISK. Needs a fresh pull or delivery. EXTENDED Same clip, NEW duration is longer. Additional frames are needed — check VFX delivery spec and music cue boundaries. CHANGED Same clip name, but the source timecode changed — a different take, retime, or pick-up. Content may be completely different despite the same slot in the cut. TRIMMED Same clip, NEW duration is shorter. VFX work window shrank — confirm the delivery still fits the tighter cut. REMOVED Present in OLD but completely absent from NEW. The shot was cut. Flag for VFX / music so work-in-progress can be halted.

UNCHANGED clips (same content within ±2 frames) are hidden by default to keep the view focused on what actually changed. Use the ALL filter to reveal them.

3
Risk scoring — know what needs action first

Each event is automatically rated by urgency using the coloured pip on the left of every table row:

HIGH Any NEW event, or any change longer than 240 frames (~10 s). These require immediate review — VFX plates, music cues, and ADR may all be affected. MED Duration 48 – 240 frames (~2–10 s). Important but manageable — schedule review within this turnover cycle. LOW Duration under 48 frames (~2 s). Small trim — likely no downstream impact but worth confirming.
Start every review pass with the Risk → high filter active. Clear all HIGH items before moving to MED.
4
Reading the timeline — zones explained

The timeline canvas has four stacked zones (top → bottom). The OLD track sits directly above the NEW track so you can see both cuts at the same programme position side by side.

RULER Each clip in the ruler shows its duration in seconds as a white number — for example 21 means that clip is 21 s long. When a clip is EXTENDED or TRIMMED a delta label like +2e 55s floats above it, showing how much longer or shorter it became. Tick marks between labels give the absolute programme timecode scale. OLD TRACK Upper filmstrip row — the previous cut. If an OLD video is loaded, each clip shows a real frame thumbnail. The currently selected event is outlined in red/amber so you always know what the Inspector is showing. NEW TRACK Lower filmstrip row — the current cut. A coloured stripe along the bottom edge of each clip shows its diff classification: cyan = NEW · green = EXTENDED · amber = CHANGED · purple = TRIMMED. A thin red line at the very top means HIGH RISK. UNCHANGED clips have no stripe. MINI-MAP A compressed overview of the entire cut appears in the top-right corner of the timeline. Changed regions glow with their diff colour. Use it to spot dense revision clusters before zooming in. The white rectangle shows your current viewport.

Delta labels decoded: +2e 55s = EXTENDED by 55 s starting at 2 events in · −38s = TRIMMED by 38 s · 81s alone = clip duration with no change. Labels only appear when the clip is wide enough to fit text at the current zoom level.

Scroll wheel zooms around the cursor. Drag pans when zoomed. Double-click resets to full cut. The zoom ratio is shown in the top-right of the canvas.
5
How to see shot cuts and structural changes

A structural change is where the edit point itself moved — a shot was inserted, removed, or repositioned. Here's how to read them:

Inserted shot A cyan NEW block appears between two UNCHANGED clips. Every clip after the insertion will have a later RecIn — even if its content didn't change. Tighter cut A purple TRIMMED bar on a clip whose adjacent clips are UNCHANGED means the editor took frames off that specific shot without touching anything else. Take swap An CHANGED event with the same duration but a different SrcIn means the editor swapped to a different take. The slot in the cut looks identical but the content is different.

Click any event in the table → the timeline zooms and centres on that clip so you can see its neighbours and understand context.

Open the Inspector for any event to compare OLD RecIn/RecOut vs NEW RecIn/RecOut — the difference is exactly how far the cut point moved in the programme.
6
Inspector panel — deep-dive on any event

Click a table row to open the inspector on the right. It shows full OLD vs NEW timecodes, a match confidence score, and editable Status + Notes fields.

75–100% High confidence match — the engine found the correct OLD clip. 50–74% Moderate confidence — verify the match visually in the compare panel. < 50% Low confidence — the clip may have been incorrectly matched; review manually.

Use the Status field to mark events as reviewed (✓ ok), skipped (⊘), or needing follow-up (?). The Note field appears in all exports — write action items directly here.

7
Video compare — 6 modes

Load video files to unlock frame-accurate comparison. Select a mode from the panel buttons:

Wipe Drag the split line to reveal OLD left / NEW right. Best for checking framing and composition changes. Side-by-Side Both videos play simultaneously — OLD left, NEW right. Good for pacing and energy comparison. A/B Full-screen toggle — click canvas to flip between OLD and NEW. Fastest way to judge take changes. Diff Pixel-difference matte. Identical pixels = black; changed pixels = bright. HUD shows "Diff X%" — a pure grade change reads 30–50%, a brand-new shot reads 90–100%. Heat Colour-coded diff: green (small) → amber (medium) → red (large). Shows where in frame the change is concentrated. Split Each half fills its side (cropped). Useful for comparing wide vs tight framings.
Enable Chain mode to automatically align OLD video to the matched source timecode whenever you select an event — so OLD and NEW always show the same shot simultaneously, even if their programme timecodes differ.
8
Export — three formats

Click the amber Export ▾ button:

Pull EDL CMX 3600 EDL of NEW + EXTENDED + CHANGED events only. Send to online suite or VFX pull system. Events marked ⊘ skip are excluded. Auto-splits at 1 500 events. PDF Report Print-ready change list with frame thumbnails, type/risk badges, match scores, your status flags, and a separate Audio Reference table sorted by programme timecode. Use the in-popup Print button to save as PDF. XLS Change List Native .xlsx workbook (4 sheets: Change List · Audio Ref · Removed · Summary) with embedded 120×68 frame thumbnails, colour-coded cells, and your notes. Works in Excel and Numbers.

PLATE LINK — How to Use
1
Scan your VFX delivery folder

Click Import Folder (or drag-and-drop a folder onto the panel) to select the root directory of your VFX deliveries. PostFlowX scans the entire tree instantly — no upload, all processing is local and private.

The scanner looks inside every sub-folder for these file types:

SEQImage sequences — .exr, .dpx, .tif, .tiff, .jpg, .png. A numbered sequence is detected automatically from the filename pattern (e.g. SHOT_0001.exr). Reads resolution and colour space from EXR headers where available. EDLCut reference files — .edl, .fcpxml, .xml. The EDL is read to extract Rec In / Rec Out, Src In / Src Out, reel name, and any clip comments (CDL, ASC, speed notes). CDLLook / colour correction files — .cc, .cdl, .ccc, .cube. Presence of a look file earns the CDL chip on each shot row. QTQuickTime preview movies — .mov, .mp4. One QT per shot is linked for in-app playback.
Expected structure: VFX_ROOT / SHOT_NAME / (SEQ + EDL + CDL + QT files). Shot names can be nested one level deep. Flat structures (all files in root) are also supported.
2
Read the shot list — status chips & colour bar

After scanning, the left panel shows every detected shot grouped by the first three parts of the shot name (e.g. ELS_D1_MPC becomes one group). Each row has:

Left border colour■ Green = SEQ + EDL both present (ready). ■ Amber = SEQ found but no EDL. ■ Red = no SEQ detected. SEQ chipGreen = image sequence found. Red = missing. EDL chipGreen = cut reference found. Red = missing. CDL chipPurple = look / CDL file found. Grey = none (not a blocker). Frame countTotal frames in the sequence (e.g. 120f). Helps verify plate length against the EDL cut.

The group header shows the group name, a colour-coded progress bar (green = all ready, amber = partial, red = none ready), and a ready/total count.

Click a group header to collapse or expand it. Click any shot row to load its QT preview and detail inspector on the right.
3
Filter, search and select shots

Use the toolbar above the shot list to narrow down what you're looking at:

AllShow every detected shot (default). ReadyOnly shots that have both a SEQ and an EDL — safe to export. Missing SEQShots where no image sequence was detected — need chasing from the vendor. Missing EDLShots that have plates but no cut reference. Export will lack timing data. No LookShots missing a CDL / LUT file — colour correction not yet delivered.

Search box — type part of a shot name to instantly filter. Matching groups auto-expand. Results show a matched / total counter.

Checkboxes — tick individual shots or use the select-all checkbox in the toolbar. Only checked shots are included in exports. Uncheck a shot to exclude it without deleting it from the list.

4
QuickTime preview — review plates in-app

Click any shot row to load its linked QuickTime movie into the right-side preview player. The player supports standard scrubbing, play/pause, and loop. No external app is needed.

If the QT preview shows "Re-import folder to enable preview", click the Re-link video previews button and select the same VFX root folder again. This restores file access after a browser restart without re-scanning the full folder.

If a shot shows "No QuickTime reference found" it means no .mov or .mp4 was detected in that shot's folder. Ask the vendor to include a proxy file alongside the plates.
Drag-and-drop your VFX folder onto the Plate Link panel to automatically save folder access. This means the QT preview will restore itself on the next browser restart without any extra clicks.
5
Shot inspector — sequence, EDL events, look

Clicking a shot row fills the inspector panel below the video with three columns of technical detail:

Column 1 — SequenceFile pattern (relative path), frame range Start–End, total frame count, resolution (W×H), colour space/gamma read from the EXR header, QT file name. A Frame Verify row compares sequence length against EDL duration — shows ✓ if they match or a ±N frame discrepancy if not. Column 2 — EDL EventsEach cut event from the EDL that references this shot: event number, Rec In / Rec Out, source In / Out, clip name, duration in frames, speed percentage (if retimed), and any inline comments (CDL / ASC grades, VFX notes, clip-name lines). Column 3 — Look / CameraCDL / LUT file path, grade type (CC, CCC, CDL, CUBE). If the folder also has EXR plates, the camera and lens metadata extracted from the EXR header (camera model, lens, focal length, T-stop, focus distance) is shown here.

The status chips at the top of the inspector (SEQ / EDL / CDL) repeat the row-level badges at a larger size for quick confirmation. Click the sequence file path to copy the folder path to the clipboard.

6
Export compositor project files (AE & Nuke)

Use the AE and Nuke buttons to generate starter projects pre-wired to your plate paths. Only checked shots are exported. If you scanned a folder using drag-and-drop (or previously confirmed folder access), the files are written directly to the VFX root folder — no save dialog needed.

AE JSXAn After Effects ExtendScript (.jsx) that builds the project automatically when run from File › Scripts › Run Script File. Creates one composition per shot, imports the plate sequence at native resolution and frame rate, adds a CDL adjustment layer if a look file was found. Nuke NKA Nuke script (.nk) with one Read node per shot, using the detected file pattern. Frame range is taken from the sequence. A Grade node with the CDL values is wired in series if a CDL file was found.
On the first export after a page reload, Plate Link will ask you to select the VFX root folder once to confirm write permission. After that, all subsequent exports save directly with no dialog.
7
Export the VFX Shots List for production

Click VFX Shots List ▾ and choose a delivery format. All formats include only the currently checked shots.

Excel (V5)Full production-ready spreadsheet. Columns: Shot, Reel, Src In/Out, Duration (frames), Resolution, Colour Space, CDL, Camera, Lens, Focal Length, T-Stop, Status. Includes a thumbnail column if QT proxy movies were found. PDFFormatted printable report — one shot per row in a table layout. Suitable for vendor hand-offs and spotting sessions. CSVLightweight plain-text summary — ideal for importing into Google Sheets, Shotgun, ftrack, or any production tracker.

The Export ▾ button gives two additional formats for pipeline integration:

JSON MappingA machine-readable JSON file mapping every shot to its plate path, frame range, resolution, EDL events, and CDL data. Use this to feed custom pipeline tools. Nuke PYA Python script for Nuke that creates the same node graph as the NK export but can be customised and run inside Nuke's Script Editor.
8
Session restore — your project survives a browser restart

Plate Link automatically saves a compact snapshot of the scan result (shot names, status flags, frame ranges, file paths) to local browser storage. When you reopen the extension or click the Plate Link tab, the shot list, inspector, and status chips are restored instantly — no re-scan needed.

QuickTime previews are File objects and cannot be persisted directly. Plate Link restores them silently in the background by re-walking the saved folder handle (granted when you dragged the folder in, or when you confirmed access on the first export). If the folder has moved or the browser needs re-authorisation, a Re-link video previews button will appear — click it and select your VFX root folder to restore all QT playback immediately.

For the most reliable auto-restore of QT previews, always load your VFX folder by dragging it onto the Plate Link panel rather than using the Import Folder button. Drag-and-drop captures the folder handle in one step.
9
Start Fresh — clearing the current project

Click Start Fresh (top-right toolbar) to wipe the entire current project from all tabs at once. In Plate Link specifically, this:

  • Stops and releases the QuickTime video pipeline
  • Clears the shot list, inspector, and all KPI counts
  • Resets the search field and all filter pills to All
  • Removes the saved scan snapshot from local storage so it won't restore on the next page open
  • Hides the progress bar and closes any open export menus

Re-importing the same folder after Start Fresh will perform a full re-scan and update all status chips to reflect the current state of the files on disk — useful when a vendor has delivered new plates since your last scan.

          Timeline Convert — How to Use
        

        

          
          
        

      


      


        
        

          
1

          

            
What Timeline Convert does

            
Timeline Convert is a fast format bridge. It reads the timeline already loaded in PostFlowX and re-exports it in any NLE format — or imports a new timeline file to replace the active cut. No re-importing from the NLE needed.

            
Two modes — one button:

            

              Export (default)Take the current timeline (EDL, FCPXML, or any imported format) and re-emit it as a different format. Useful when your DI suite needs FCPXML but editorial handed you an EDL, or the client asks for FCP7 XML alongside your OTIO deliverable.
              ImportBring in a new timeline file — drag-and-drop or browse — and load it into PostFlowX as the active cut. The imported timeline replaces the current one and is immediately available for all PostFlowX tools.
            

          

        


        
        

          
2

          

            
Export a timeline to a new format

            
    
              
  1. Open a timeline in any PostFlowX tab (Pull Prep, CUT DIFF, etc.) first
    2. 
              
  2. Click the TL Convert button in the left toolbox (or any tab's export area)
    3. 
              
  3. The modal opens in Export mode — the preview pane shows the output immediately
    4. 
              
  4. Pick a format tab at the top of the modal to switch output format
    5. 
              
  5. Click Copy to copy the text to the clipboard, or Download to save the file
    6. 
            

            

              
              The preview auto-refreshes every time you switch format tab or change reel mode — no extra button needed.
            

          

        


        
        

          
3

          

            
Format guide — pick the right tab for your NLE

            

              EDL32CMX 3600 EDL — the industry-standard interchange format. Accepted by DaVinci Resolve, Avid Media Composer, Baselight, and virtually every DI / conform system. Use for media pulls, re-conforms, and any NLE that doesn't have native XML import.
              OTIOOpenTimelineIO — the open interchange standard for pipeline and scripting use. Import into Resolve, Flame, Hiero, Nuke Studio, or any pipeline tool that supports the OTIO spec. Best for handing off to engineering pipelines or automated workflows.
              FCPXMLFinal Cut Pro X XML — the native format for Final Cut Pro X. Also accepted by DaVinci Resolve 16+ for direct timeline import. Preserves track structure, clip names, and record timecodes.
              FCPXMLDFCPXML Package — the same XML wrapped in a .fcpxmld folder structure that Final Cut Pro uses when saving bundles. Use this when the target app specifically asks for a bundle rather than a raw .fcpxml file.
              FCP7 XMLFCP 7 / xmeml XML — legacy Final Cut Pro 7 format. Accepted by Adobe Premiere Pro, Avid, and older Resolve versions. Use for Premiere Pro round-trips or when the pipeline requires xmeml compatibility.
              AAFAAF (Avid AAFXML) — Avid Media Composer's native sequence format. Exports as AAFXML with SMPTE UMID MobIDs, a TapeDescriptor per reel, and drop-frame timecode detection. Import directly into Avid Media Composer via File → Import.
            

          

        


        
        

          
4

          

            
Reel name source — control how clips are named

            
The Reel / Clip name / Filename radio strip in the toolbar controls what goes into the reel/tape name field of the exported file. This matters for Avid reconform and DI media linking where the reel name must match the actual media.

            

              ReelUse the original reel name from the source timeline (e.g. A001C001). This is the default and preserves the original conform identity. Choose this for DI pulls and Avid reconforms.
              Clip nameUse the clip name instead of the reel (e.g. INT_KITCHEN_DAY_01). Choose this when clip names carry the meaningful identity and reel names are generic camera roll codes.
              FilenameUse the source filename (minus extension) as the reel name. Useful when re-importing media that was renamed during offline — the filename and the media file will match.
            

            

              
              Reel names are automatically sanitised — trailing version suffixes (_v1, -v001) and trailing separators are stripped so they don't interfere with media linking.

Import — load a new timeline into PostFlowX

            
Click the IMPORT button (amber outline, top-left of the modal) to switch to Import mode. Then either:

            
    
              
  • Drag-and-drop a timeline file onto the drop zone
    • 
              
  • Click Browse Files… to open a file picker
    • 
            

            
Supported import formats:

            

              .edlCMX 3600 EDL — from any NLE or DI system.
              .fcpxmlFinal Cut Pro X XML — from FCP X, DaVinci Resolve 19+, or Premiere via XML export.
              .fcpxmldFCP X bundle folder — drop the whole folder; PostFlowX reads the XML inside automatically.
              .xmlFCP 7 / xmeml — from Premiere Pro, older Resolve, or FCP 7.
              .otio / .jsonOpenTimelineIO — from pipeline tools or Hiero / Nuke Studio.
            

            
After import the modal closes automatically and the new timeline becomes the active cut across all PostFlowX tabs. Click IMPORT again to go back to Export mode at any time.

            

              
              You can also drag a timeline file directly onto any PostFlowX tab (Pull Prep event panel, CUT DIFF dropzone, etc.) without opening Timeline Convert — that path also loads the file as the active cut.
