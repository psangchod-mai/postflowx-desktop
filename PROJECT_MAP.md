## Build Commands

| What you want | Command |
|---|---|
| Quick dev (loads src/ directly, no build) | `npm run dev` |
| Dev with fresh renderer build | `npm run dev:mac` |
| Build desktop renderer only | `npm run build:renderer` |
| Build extension renderer only | `npm run build:renderer:extension` |
| Package macOS .app | `npm run build:mac-dir` |
| Full release build | `npm run build:mac` |
| Prep Chrome extension for loading | `npm run build:extension` |

> **Rule:** After any UI source change, run `npm run build:renderer` before rebuilding the .app.  
> In dev, `npm run dev` loads `src/` directly — no build step needed.

## How the two targets differ at runtime

| | Chrome Extension | Desktop App |
|---|---|---|
| Entry | `dist/extension/index.html` (load as unpacked) | `dist/desktop/index.html` (packaged in asar) |
| Dev entry | `src/index.html` (via `npm run dev:mac`) | `src/index.html` (via `npm run dev`) |
| Chrome APIs | Native `chrome.*` | Shimmed by `electron_shim.js` via `preload.js` |
| Platform detection | `window.__PFX_TARGET__ === "extension"` | `window.pfxPlatform.isMacApp === true` or `window.__PFX_TARGET__ === "desktop"` |
| First screen | Pull Prep | Home / Entry Screen |
| Native media | Not available | `window.pfxPlatform.media.*` (AVFoundation) |
| Native commands | Not available | `window.pfxPlatform.sendNativeCommand(...)` |
| Background process | `extension/background.js` service worker | `electron/companion.js` → Python server |

## Key platform guards in source code

```js
// Check if running in desktop Electron app
const isDesktop = !!(window.pfxPlatform?.isMacApp) || window.__PFX_TARGET__ === 'desktop';

// Check if native media engine is available (desktop only)
const hasMedia = !!(window.pfxPlatform?.media);

// Send a native command (desktop only, no-op in extension)
window.pfxPlatform?.sendNativeCommand({ type: 'resolve.status', payload: {} });
```

## Adding a new feature

- **Shared UI** → add to `src/scripts/features/` or `src/scripts/modules/`. Works in both targets automatically.
- **Desktop-only** (native media, Resolve, file system) → gate with `window.pfxPlatform?.isMacApp`, add IPC handler in `electron/ipc.js`.
- **Extension-only** (chrome.tabs, chrome.identity) → gate with `window.chrome?.runtime?.id`.
- **New IPC channel** → add handler in `electron/ipc.js`, expose in `electron/preload.js` under `pfxPlatform`.
