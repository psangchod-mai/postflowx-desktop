## 1. CUT DIFF 2.0 คืออะไร?

CUT DIFF 2.0 เปรียบเทียบไทม์ไลน์ที่ตัดต่อสองเวอร์ชัน — **ตัดเก่า (OLD)** และ **ตัดใหม่ (NEW)** — แล้วแสดงว่ามีอะไรเปลี่ยนแปลงระหว่างสองเวอร์ชันนั้น ระบบตอบคำถามเหล่านี้:

- มีคลิปใดถูกเพิ่ม ลบ หรือแทนที่บ้าง?
- มีช็อตใดที่ขยายหรือตัดทอนบ้าง?
- เพิ่มหรือลดเวลาหน้าจอไปเท่าไหร่?
- การเปลี่ยนแปลงใดมีความเสี่ยงสูงและต้องการความสนใจจาก VFX/เสียง/ดนตรีทันที?

ออกแบบมาสำหรับ **การส่งมอบงานตัดต่อ**: ผู้ประสานงาน VFX, ผู้ช่วยบรรณาธิการ, ผู้ตัดต่อเสียง และผู้ดูแลดนตรีที่ต้องการเข้าใจการแก้ไขภาพล็อคอย่างรวดเร็ว

**รูปแบบไฟล์ที่รองรับ**: EDL (CMX 3600), FCPXML, ALE, XML ส่งออกจาก DaVinci Resolve, Avid, Premiere และ Final Cut Pro X

## 2. การโหลดไทม์ไลน์

### โซนวางไฟล์

ที่ด้านบนของแท็บจะมีโซนวางไฟล์สองโซน:

```
┌────────────────────┐   ┌────────────────────┐
│  วางไทม์ไลน์เก่า   │   │  วางไทม์ไลน์ใหม่   │
│  หรือคลิก Browse   │   │  หรือคลิก Browse   │
└────────────────────┘   └────────────────────┘
```

- **โซนซ้าย = OLD** — เวอร์ชันก่อนหน้า (ข้อมูลอ้างอิง/ฐาน)
- **โซนขวา = NEW** — เวอร์ชันที่อัปเดตที่ได้รับจากการตัดต่อ

ลากและวางไฟล์ลงบนแต่ละโซน หรือคลิก **Browse** เพื่อเลือกไฟล์ เมื่อโหลดไฟล์แล้ว ชื่อไฟล์จะปรากฏในโซนและโซนจะเปลี่ยนเป็นสีไฮไลต์

### ไฟล์ไหนคือ OLD และไฟล์ไหนคือ NEW?

โหลดเวอร์ชัน **เก่ากว่า** เป็น OLD และเวอร์ชัน **ใหม่กว่า** เป็น NEW เสมอ ทิศทางของ diff มีความสำคัญ: เหตุการณ์จะถูกทำเครื่องหมายว่า EXTENDED เมื่อคลิปใน NEW ยาวกว่าคลิปใน OLD หากโหลดสลับกัน ป้ายกำกับ EXTENDED/TRIMMED ทั้งหมดจะกลับด้าน

### การโหลดไฟล์วิดีโอ (ไม่บังคับแต่แนะนำ)

ด้านล่างโซนวางไฟล์คือแผง **Video Compare** คุณสามารถวางหรือเรียกดูไฟล์วิดีโอจริงของ OLD และ NEW ซึ่งจะเปิดใช้งาน:

- แถบฟิล์มสตริปภาพขนาดย่อที่แม่นยำระดับเฟรม
- การเปรียบเทียบวิดีโอแบบ side-by-side / wipe / difference
- กราฟ content diff ระดับพิกเซลใต้ไทม์ไลน์

ไฟล์วิดีโอถูกจัดเก็บใน IndexedDB ของเบราว์เซอร์ จึงถูกจดจำระหว่างเซสชัน

## 3. การวิเคราะห์ความแตกต่าง

คลิกปุ่ม **Analyze** ในส่วนหัว ซึ่งจะเริ่มต้นเครื่องมือ diff ที่:

1. แยกวิเคราะห์คลิปทั้งหมดจากทั้งสองไทม์ไลน์
2. จับคู่คลิป NEW แต่ละคลิปกับคู่เทียบที่ดีที่สุดใน OLD โดยใช้ **ตัวตนของคลิป** (ชื่อคลิป + รีล)
3. จำแนกแต่ละคู่เป็นประเภท diff (NEW, EXTENDED, CHANGED, TRIMMED)
4. คำนวณ **คะแนนความเสี่ยง** สำหรับแต่ละการเปลี่ยนแปลง
5. แสดงแถบ KPI, ไทม์ไลน์ และตาราง

การ diff ทำงานทั้งหมดในเบราว์เซอร์ — ไม่มีการอัปโหลด ไม่มีเซิร์ฟเวอร์

### แถบ KPI

หลังการวิเคราะห์ จะปรากฏการ์ดตัวชี้วัดหนึ่งแถว:

| การ์ด | สิ่งที่แสดง |
|------|------------|
| **NEW** | คลิปที่ปรากฏใน NEW แต่ไม่มีคลิปที่ตรงกันใน OLD |
| **EXTENDED** | คลิปที่ระยะเวลาเพิ่มขึ้นระหว่าง OLD และ NEW |
| **CHANGED** | ชื่อคลิปเดียวกัน แต่เนื้อหาหรือเทคต่างกัน |
| **TRIMMED** | คลิปที่ระยะเวลาลดลง |
| **HIGH RISK** | เหตุการณ์ที่ต้องการความสนใจทันที (ดูหัวข้อ 5) |
| **+DUR** | เวลาหน้าจอที่เพิ่มทั้งหมด (เฟรม NEW + EXTENDED) |
| **−DUR** | เวลาหน้าจอที่ลดลงทั้งหมด (เฟรม TRIMMED) |
| **% Changed** | สัดส่วนของการตัดที่เปลี่ยนแปลง |

แถบความคืบหน้าที่ขวาสุดแสดงสัดส่วนของคลิปที่เปลี่ยนแปลงกับไม่เปลี่ยนแปลงในมุมมองเดียว

## 4. ประเภทของความแตกต่าง

เครื่องมือเปรียบเทียบคลิป NEW แต่ละคลิปกับคลิป OLD ที่มี **ชื่อและรีลเดียวกัน** เมื่อพบคู่ที่ตรงกัน ระยะเวลาและจุดเริ่มต้นซอร์สจะถูกเปรียบเทียบภายในค่าความคลาดเคลื่อนเล็กน้อย (±2 เฟรมระยะเวลา, ±4 เฟรมซอร์ส-อิน)

### NEW
```
OLD: [ไม่มี]
NEW: [████████ CLIP_A ████████]
```
คลิปมีอยู่ใน NEW แต่ **ไม่มีคลิปที่มีตัวตนเดียวกัน** ใน OLD ทั้งหมด เหตุการณ์ NEW ถือเป็น **ความเสี่ยงสูงโดยอัตโนมัติ**

### EXTENDED
```
OLD: [████████ CLIP_B ████████]         (200 เฟรม)
NEW: [█████████████ CLIP_B █████████]   (260 เฟรม + 60 เฟรมที่เพิ่ม)
```
คลิปเดียวกัน แต่เวอร์ชัน NEW **ยาวกว่า** สำหรับ VFX มักหมายความว่าต้องขยายหน้าต่างงาน VFX

### TRIMMED
```
OLD: [█████████████ CLIP_C █████████]   (180 เฟรม)
NEW: [████ CLIP_C ████]                  (80 เฟรม — ลบออก 100 เฟรม)
```
คลิปเดียวกัน แต่เวอร์ชัน NEW **สั้นกว่า** สำหรับ VFX งานอาจเริ่มช้าลงหรือสิ้นสุดเร็วกว่าที่งบประมาณไว้

### CHANGED
```
OLD: [████ CLIP_D (srcIn=00:42:15:00) ████]
NEW: [████ CLIP_D (srcIn=01:12:30:08) ████]   ชื่อเดียวกัน แต่ซอร์สต่างกันโดยสิ้นเชิง
```
ชื่อคลิปเดียวกัน แต่ซอร์สไทม์โค้ด (srcIn) แตกต่างกันเกินค่าความคลาดเคลื่อน บ่งชี้ว่าเป็นเทคต่างกัน หรือเวอร์ชันที่ปรับความเร็ว/เกรดใหม่

### UNCHANGED
```
OLD: [████ CLIP_E ████]  (srcIn=00:10:00:00, dur=120fr)
NEW: [████ CLIP_E ████]  (srcIn=00:10:00:00, dur=120fr) — เหมือนกัน
```
คลิปเหมือนกันในทั้งสองเวอร์ชันภายในค่าความคลาดเคลื่อน เหตุการณ์ UNCHANGED จะ **ซ่อนไว้จากตาราง** โดยค่าเริ่มต้น

## 5. การให้คะแนนความเสี่ยง

เหตุการณ์ diff ทุกอันได้รับระดับความเสี่ยงตามความหมายสำหรับงานปลายทาง

### ระดับความเสี่ยง

| ระดับ | สี | กฎ |
|-------|----|----|
| **สูง** | 🔴 แดง | เหตุการณ์ NEW ใดๆ **หรือ** เหตุการณ์ที่ยาวกว่า 240 เฟรม (~10 วินาที ที่ 24fps) |
| **กลาง** | 🟡 เหลืองอำพัน | ระยะเวลาเหตุการณ์ 48–240 เฟรม (~2–10 วินาที) |
| **ต่ำ** | 🟢 เขียว | ระยะเวลาเหตุการณ์ต่ำกว่า 48 เฟรม (~2 วินาที) |

### คะแนนการจับคู่ (% ความมั่นใจ)

สำหรับเหตุการณ์ EXTENDED, CHANGED และ TRIMMED เครื่องมือยังรายงาน **ความมั่นใจในการจับคู่** 0–100%:

- **100%**: จับคู่สมบูรณ์แบบ
- **75–99%**: การตัดเล็กน้อยหรือการปรับซอร์สเล็กน้อย — ความมั่นใจสูง
- **50–74%**: ความแตกต่างปานกลาง — ควรตรวจสอบ
- **< 50%**: ความแตกต่างมาก — อาจเป็นการจับคู่ผิด

คะแนนคำนวณจาก:
`(ความคล้ายคลึงระยะเวลา × 60%) + (ความคล้ายคลึงซอร์ส-อิน × 40%)`

## 6. การอ่านไทม์ไลน์

ไทม์ไลน์เป็นส่วนที่ทรงพลังที่สุดของ CUT DIFF 2.0 แสดงทั้ง OLD และ NEW แบบคู่ขนานเป็นแทร็กแนวนอน

### เค้าโครงไทม์ไลน์ (บนลงล่าง)

```
┌─────────────────────────────────────────────────────────────┐
│ RULER  │ 00:00   00:30   01:00   01:30   02:00              │ ← ไม้บรรทัดไทม์โค้ด
├────────────────────────────────────────────────────────────┤
│  OLD ░░░░▓▓▓▓▓░░▓▓▓▓░░░░░░▓▓░░░░░░▓▓▓░░░░░░░░░░░░░░░░░░░  │ ← แทร็ก OLD
│ ─────────────────── DIFF ──────────────────────────────────── │ ← ตัวคั่น Diff
│  NEW ░░░▓▓▓▓░░░░░░░▓▓▓▓▓▓░░░▓░░░░░░░▓▓▓░░░░░░░░░░░░░░░░░░  │ ← แทร็ก NEW

└─────────────────────────────────────────────────────────────┘
```

### แทร็ก NEW และแถบสี Diff

แทร็ก NEW แสดงคลิปแต่ละอันพร้อม **แถบสีที่ด้านล่าง** บ่งชี้สถานะ diff:

| สี | ประเภท Diff | ความหมาย |
|----|-------------|----------|
| 🔵 ฟ้าสว่าง | NEW | ไม่เคยเห็นมาก่อน — ไม่มีใน OLD |
| 🟢 เขียว | EXTENDED | คลิปนี้ยาวขึ้นเมื่อเทียบกับ OLD |
| 🟡 เหลืองอำพัน | CHANGED | ชื่อเดียวกัน ซอร์ส/เทคต่างกัน |
| 🟣 ม่วง | TRIMMED | คลิปนี้สั้นลงเมื่อเทียบกับ OLD |
| ⬛ เข้มมาก | UNCHANGED | เหมือนกับ OLD |

**แถบสีแดง 2px ที่ด้านบน** ของคลิปหมายถึงความเสี่ยงสูง

### กราฟ Content Diff

กราฟแท่งด้านล่างแถบสรุปแสดง **ความคล้ายคลึงของเฟรมระดับพิกเซล** ระหว่าง OLD และ NEW

| สี | ความหมาย |
|----|----------|
| 🟢 แถบเขียว | เฟรมดูเกือบเหมือนกัน |
| 🟡 แถบเหลือง | ความแตกต่างทางภาพปานกลาง |
| 🔴 แถบแดง | เฟรมแตกต่างกันมากทางภาพ |

## 7. จุดตัดและวิธีสังเกต

### วิธีดูจุดตัดในไทม์ไลน์

**วิธีที่ 1: ดูจุดเริ่มต้น/สิ้นสุดของคลิปในแทร็ก NEW**

เมื่อแถบสี diff ของคลิปที่อยู่ติดกันเป็นประเภทต่างกัน แสดงว่ามีการเปลี่ยนแปลงจุดตัดที่สำคัญ

**วิธีที่ 2: ซูมเข้าในส่วนที่เปลี่ยนแปลง**

ใช้ **วงล้อเลื่อนเพื่อซูม** บนไทม์ไลน์ เมื่อซูมเข้า เครื่องหมายบนไม้บรรทัดจะละเอียดขึ้นและช็อตแต่ละอันจะมองเห็นได้

**วิธีที่ 3: ดูกลุ่มสีในแถบสรุป**

แถบสรุปแสดงการตัดทั้งหมดแบบบีบอัด กลุ่มสี (ฟ้า/เหลือง/เขียว) หมายถึงโซนที่มีการแก้ไขหนาแน่น

**วิธีที่ 4: เปรียบเทียบขอบคลิป OLD และ NEW โดยตรง**

เลือกเหตุการณ์ TRIMMED ในตาราง ผู้ตรวจสอบจะแสดงค่า `RecIn`/`RecOut` ทั้ง OLD และ NEW ความแตกต่างคือปริมาณที่จุดตัดเคลื่อน

## 8. ตารางความแตกต่าง

ตารางแสดงเหตุการณ์ที่เปลี่ยนแปลงทุกอันเป็นแถว

### คู่มือคอลัมน์

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| **●** | จุดความเสี่ยง — แดง (สูง), เหลือง (กลาง), เขียว (ต่ำ) |
| **Type** | ป้าย NEW / EXT / CHG / TRM / UNC |
| **Reel** | ชื่อรีลหรือถังจาก EDL/XML |
| **Clip** | ชื่อคลิป |
| **SrcIn** | ไทม์โค้ดซอร์สเริ่มต้น |
| **Dur** | ระยะเวลาในเฟรม |
| **Match%** | คะแนนความมั่นใจ (แถบ + %) — ว่างสำหรับเหตุการณ์ NEW |
| **Status** | สถานะการตรวจสอบของคุณ: — / ✓ / ⊘ / ? (คลิกเพื่อสลับ) |
| **Note** | ช่องข้อความอิสระ (มองเห็นในผู้ตรวจสอบ) |

### การเลือกแถว

คลิกแถวใดก็ได้เพื่อ:
1. **เปิดผู้ตรวจสอบ** (แผงขวา) พร้อมรายละเอียดเหตุการณ์ครบถ้วน
2. **ซูมไทม์ไลน์** เพื่อให้เหตุการณ์นั้นอยู่ตรงกลาง
3. **เลื่อนวิดีโอ** ไปยังไทม์โค้ด `RecIn` ของเหตุการณ์ (หากโหลดวิดีโอแล้ว)

## 9. แผงตรวจสอบ

คลิกแถวใดก็ได้เพื่อเปิดผู้ตรวจสอบทางด้านขวา แสดงรายละเอียดครบถ้วนของการเปลี่ยนแปลงที่เลือก

### ช่องข้อมูล

```
เหตุการณ์ 3 / 47              ← หมายเลขเหตุการณ์จากทั้งหมด
Type:    EXTENDED              ← การจัดประเภท diff
Reel:    A001                  ← ชื่อรีล
Clip:    105_08_06/01_AB       ← ชื่อคลิป
SrcIn:   10:42:15:00           ← ซอร์สเริ่มต้นใน NEW
SrcOut:  10:42:28:10           ← ซอร์สสิ้นสุดใน NEW
RecIn:   01:02:45:00           ← เริ่มต้น (โปรแกรม)
RecOut:  01:02:58:10           ← สิ้นสุด (โปรแกรม)
Duration: 318 เฟรม
FPS:      24
```

### ข้อมูลการจับคู่ (สำหรับ EXTENDED / TRIMMED / CHANGED)

```
Match Score:  ████████░░  78%  ← แถบความมั่นใจ
Reason:       Duration +48fr (+2.0s extended)
Old Clip:     105_08_06/01_AB  ← คลิปเดียวกันใน OLD
Old SrcIn:    10:42:15:00      ← ซอร์สเริ่มต้นใน OLD
Old RecIn:    01:02:45:00      ← เริ่มต้นบันทึกใน OLD
```

### สถานะและบันทึก

**สถานะ** (คลิกหรือกด Enter เพื่อสลับ):
- **—** (ไม่มี): ยังไม่ได้ตรวจสอบ
- **✓** (ตกลง): ยืนยันแล้ว ไม่ต้องดำเนินการ
- **⊘** (ข้าม): ทราบปัญหาแล้ว ข้ามในรอบนี้
- **?** (สอบถาม): ต้องการติดตามหรือหารือ

บันทึกจะปรากฏทั้งในการส่งออก PDF และ XLSX

## 10. การเปรียบเทียบวิดีโอ

โหลดไฟล์วิดีโอสำหรับ OLD และ NEW เพื่อปลดล็อกแผงเปรียบเทียบเต็มรูปแบบ

### โหมดการเปรียบเทียบ

#### Wipe
แถบแนวตั้งแบ่งหน้าจอ ลากแถบซ้าย/ขวาเพื่อเปิดเผย OLD (ซ้าย) หรือ NEW (ขวา)

#### Side by Side (SBS)
OLD เล่นที่ครึ่งซ้าย NEW เล่นที่ครึ่งขวาพร้อมกัน ทั้งสองเล่นซิงค์กัน

#### Split
เหมือน SBS แต่วิดีโอแต่ละอันเติมครึ่งหนึ่งอย่างสมบูรณ์ (ครอบตัด)

#### AB
แสดงวิดีโอหนึ่งอันในแบบเต็มหน้าจอ คลิกที่ canvas เพื่อสลับระหว่าง A (OLD) และ B (NEW)

#### Diff
แสดง **ภาพความแตกต่างระดับพิกเซล**: พิกเซลที่เหมือนกันจะดูดำ พิกเซลที่ต่างกันจะสว่าง

#### Heat
เหมือน Diff แต่ใช้รหัสสีตามขนาด:
- 🟢 เขียว: การเปลี่ยนแปลงเล็กน้อย
- 🟡 เหลือง: การเปลี่ยนแปลงปานกลาง
- 🔴 แดง: การเปลี่ยนแปลงมาก

### Chain Mode

เมื่อเปิด Chain วิดีโอ OLD จะเลื่อนไปยัง **ซอร์ส-อินของคลิป OLD** โดยอัตโนมัติเมื่อเลือกเหตุการณ์ ขณะที่ NEW เลื่อนไปยังซอร์ส-อินของคลิป NEW ใช้ Chain เมื่อตรวจสอบเหตุการณ์ CHANGED

## 11. ตัวกรอง

### ตัวกรองประเภท

คลิกปุ่มเม็ดยาเพื่อแสดงเฉพาะประเภท diff ที่ระบุ:

`ALL` `NEW` `EXTENDED` `CHANGED` `TRIMMED`

### ตัวกรองความเสี่ยง

`all` `high` `med` `low`

คลิก **high** เพื่อดูเฉพาะเหตุการณ์ที่มีความเสี่ยงสูง แนะนำให้เริ่มต้นการตรวจสอบ turnover ด้วยวิธีนี้

### การใช้ตัวกรองร่วมกัน

ตัวกรองรวมกัน: ตัวกรองประเภทและความเสี่ยงทั้งสองใช้งานพร้อมกัน เช่น ตั้ง type=EXTENDED และ risk=high เพื่อดูช็อตที่มีอยู่ซึ่งยาวเกินอย่างตันตราย

## 12. สถานะและการจดบันทึก

### รอบการตรวจสอบที่แนะนำ

1. **กรอง HIGH RISK** → ตรวจสอบรายการ HIGH ทั้งหมด → ทำเครื่องหมาย ✓ หรือ ?
2. **กรอง CHANGED** → ตรวจสอบการแทนที่เทคแต่ละอัน → บันทึกหาก VFX ต้องทำใหม่
3. **กรอง NEW** → ยืนยันช็อตใหม่กับผู้ประสานงาน → บันทึกวันที่ดึง/ส่ง
4. **กรอง EXTENDED** → ตรวจสอบว่าช็อต VFX ใดขยายเกินงบประมาณ
5. **กรอง TRIMMED** → ยืนยันว่า deliverables ยังพอดีในหน้าต่างที่ถูกตัดทอน

### ความหมายของสถานะในทางปฏิบัติ

| สถานะ | เมื่อใช้ |
|-------|---------|
| **—** | ยังไม่ได้ตรวจสอบ |
| **✓ ตกลง** | ตรวจสอบแล้ว ไม่ต้องดำเนินการ ปลอดภัยที่จะดำเนินต่อ |
| **⊘ ข้าม** | ทราบ/ตั้งใจ ข้ามในเซสชันนี้ |
| **? สอบถาม** | ต้องถามบรรณาธิการ/ผู้ประสานงานก่อนดำเนินการ |

## 13. การส่งออก

คลิกปุ่ม **Export ▾** สีเหลืองอำพันเพื่อเปิดเมนูการส่งออก

### Pull EDL

สร้าง CMX 3600 EDL ที่มีเฉพาะเหตุการณ์ **NEW, CHANGED และ EXTENDED** เหตุการณ์ที่มีสถานะ **⊘ ข้าม** จะถูกแยกออก

### PDF Report

เปิด PDF พร้อมพิมพ์ในแท็บเบราว์เซอร์ใหม่พร้อม:
- **ส่วนหัวสรุป**: ชื่อโปรเจกต์ ชื่อไฟล์ OLD/NEW วันที่ สถิติ
- **การ์ดการเปลี่ยนแปลง**: หนึ่งการ์ดต่อเหตุการณ์ที่เปลี่ยนแปลง จัดกลุ่มตามประเภท
- **รายการการเปลี่ยนแปลงเสียง**: ตารางแยกต่างหากสำหรับคลิปแทร็กเสียง

### XLSX Change List

ส่งออก `.xlsx` workbook (4 แผ่นงาน) พร้อม **ภาพขนาดย่อที่ฝังไว้**:

| แผ่นงาน | เนื้อหา |
|---------|---------|
| **Change List** | เหตุการณ์ที่เปลี่ยนแปลงทั้งหมดพร้อมภาพขนาดย่อ 120×68 |
| **Audio Ref** | เหตุการณ์ทั้งหมดจัดเรียงตาม RecIn สำหรับเสียง |
| **Removed** | คลิปที่มีใน OLD แต่ไม่มีใน NEW |
| **Summary** | ภาพรวมสถิติ: จำนวน, ระยะเวลา |

## 15. เคล็ดลับและตัวอย่างการทำงาน

### เคล็ดลับ 1: ทำงานจากไทม์ไลน์ออกไป

อย่าเริ่มที่ตาราง — เริ่มที่ไทม์ไลน์ แถบสรุปแสดงว่าการเปลี่ยนแปลงกระจุกตัวอยู่ที่ไหน ซูมเข้าไปในกลุ่มที่หนาแน่น หาขอบเขตช็อต จากนั้นคลิกเหตุการณ์แต่ละอันเพื่อเจาะลึกลงไปในผู้ตรวจสอบ

### เคล็ดลับ 2: ใช้ Wipe Mode เพื่อตรวจสอบการเปลี่ยนแปลงการจัดกรอบ

เหตุการณ์ CHANGED ที่มีคะแนนการจับคู่สูง (>75%) มักหมายความว่าบรรณาธิการใช้เฟรมเริ่มต้นที่แตกต่างเล็กน้อย เปลี่ยนไปใช้ Wipe mode และเลื่อนไปยังเฟรมแรกของช็อต

### เคล็ดลับ 3: ดูกราฟ Content Diff สำหรับการแทนที่แบบเงียบ

กราฟ content diff จับการเปลี่ยนแปลงที่ EDL ไม่สามารถจับได้ หากเห็นสไปก์ในกราฟใต้บริเวณที่ไม่มีแถบสีในแทร็ก NEW ชื่อคลิป/ไทม์โค้ดเหมือนกันแต่เนื้อหาต่างกันทางภาพ

### เคล็ดลับ 4: กรอง HIGH + CHANGED สำหรับปัญหาที่ซับซ้อนที่สุด

ความเสี่ยงสูง + ประเภท CHANGED คือสถานการณ์ที่ยากที่สุด: ช็อตยาวที่มีอยู่ถูกแทนที่ด้วยเทคอื่น ตั้ง type=CHANGED และ risk=high เพื่อแยกเหตุการณ์เหล่านี้

### เคล็ดลับ 5: ใช้บันทึกเป็นบันทึกส่งมอบ

พิมพ์รายการดำเนินการของคุณโดยตรงลงในช่อง Note ขณะตรวจสอบ เมื่อส่งออก XLSX ทุกบันทึกจะอยู่ในสเปรดชีต พร้อมแชร์กับผู้ประสานงาน VFX หรือบรรณาธิการดนตรี

### เคล็ดลับ 6: AB Mode สำหรับการเปรียบเทียบเทค

เมื่อตรวจสอบเหตุการณ์ CHANGED เข้าโหมด AB เลือกเหตุการณ์ และกดที่ canvas อย่างรวดเร็วเพื่อสลับ A/B เนื่องจาก Chain mode จัดวิดีโอทั้งสองให้เริ่มต้นช็อต คุณจึงสลับระหว่างเทค OLD และ NEW ของฉากเดียวกัน

### เคล็ดลับ 7: Multi-Part EDL สำหรับ Conform ขนาดใหญ่

หากซีเควนซ์มีเหตุการณ์ที่เปลี่ยนแปลงมากกว่า 1,500 อัน การส่งออก Pull EDL จะแยกออกเป็นหลายไฟล์โดยอัตโนมัติ
